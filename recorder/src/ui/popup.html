How to use TestCraft

Turn browser activity into a reusable test in six simple steps.

  1. 1Open the website or page you want to test.
  2. 2Select Start recording.
  3. 3Perform the actions you want your test to repeat.
  4. 4Select Stop recording when finished.
  5. 5Select Generate script to download the Playwright test.
  6. 6Use Run tests when the local API is available.
